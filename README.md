# 掌间交互

一个用双手探索的三维小世界。支持电脑与手机，开启摄像头后，手掌就是场景的控制器。也可以直接拖动、缩放、点击游玩。

**公开体验地址：https://zhangjian-jiaohu.pages.dev/**

当前版本为 **1.1.0 视觉优化版**：更新了柔光环境、材质与表面纹理，增加实际三维缩略图、连续聚散滑杆和沉浸观看模式。分散形态使用有边界的曲线路径，手机画面会收窄横向分布。

## 五种造型

| 造型 | 聚合 | 展开 |
| --- | --- | --- |
| 星际引力 | 带细腻星环的立体行星 | 许多自带星环的小行星 |
| 心动星团 | 饱满的三维心形，轻轻跳动 | 一颗颗独立的立体小爱心 |
| 记忆之树 | 带立体枝叶、玻璃挂饰与暖色灯带的圣诞树 | 金色星饰与珍藏照片 |
| 光之花园 | 从花苞到层叠柔光花，带花瓣纹理 | 花瓣离开花心，随风飘散 |
| 微光深海 | 带波纹裙边与柔软触腕的透明水母 | 一群大小不同的发光水母 |

## 开始体验

1. 点击「开启摄像头」，允许浏览器使用摄像头。手机使用前置摄像头。
2. 选择底部的系统造型，把手举到画面中，指尖完整入镜。
3. 可选：点击「加入照片」，选择最多二十四张图片。照片会进入场景，可以捏合拿到眼前，也可以直接点击或轻触查看。

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 展开、散开；花朵先绽放，再飘散 |
| 握紧拳头 | 聚合；花朵收拢成花苞 |
| 左右上下移动手掌 | 转动场景 |
| 拇指与食指捏合 | 抓住照片，或拖动场景 |
| 只伸出食指 | 在空中画出星尘 |
| 保持胜利手势约一秒 | 切换下一个造型 |
| 保持竖拇指约一秒 | 定格、继续动画 |
| 双手拉开、靠拢 | 放大、缩小场景 |

手机也支持单指拖动与双指缩放。电脑可以拖动、滚轮缩放，空格键切换展开与聚合。右侧还有展开、定格、复位、保存图片按钮。

拖动聚散滑杆可以慢慢探索中间形态；花朵依次经历花苞、绽放、飘散。点击「沉浸观看」，会收起介绍与造型卡，把画面交给三维世界；摄像头开关仍然保留，点击「返回操作」即可恢复界面。

## 本地运行

需要 Node.js 20.19 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5188/`。本机 localhost 可以开启摄像头；通过手机访问时，需要使用已发布的 HTTPS 网址。

```sh
npm test
npm run build
```

构建结果位于 `dist/`，可以部署到 Cloudflare Pages 等静态托管平台。

## Cloudflare Pages

```sh
npx wrangler@4.151.1 login --scopes account:read user:read pages:write
npx wrangler@4.151.1 pages project create zhangjian-jiaohu --production-branch main --force
npx wrangler@4.151.1 pages deploy dist --project-name zhangjian-jiaohu --branch main
```

本项目已经创建并发布，后续更新只需执行部署命令，无需重复创建项目。修改源代码后，运行测试与构建，再推送 GitHub 并执行部署。不要把账户令牌放入源代码。

## 隐私与兼容

- 摄像头画面、手势推理和照片处理均在浏览器内完成，不上传服务器，不使用麦克风。
- 照片仅保留在本次页面的内存中，刷新后清空。单张图片上限 25 MB。
- 切到后台或离开页面会关闭摄像头；回到页面后可手动再次开启。
- 需要支持 WebGL、WebAssembly、摄像头权限的现代浏览器。手机建议用系统浏览器打开；应用内浏览器若无法请求摄像头，可选择「在浏览器中打开」。
- 手机自动降低实例数量与像素密度，并以约三十帧的渲染目标控制负担；可在页面底部选择「流畅优先」。较低画质仍会保留完整的树冠与造型分布。
- 普通照片格式由浏览器解码。无法读取 HEIC 等格式时，可改用 JPEG 或 PNG。

## 实现

Three.js 负责三维实体、实例渲染、物理材质和辉光；MediaPipe Hand Landmarker 负责两只手的关键点识别。心形使用隐式曲面生成，散开的小爱心也使用真实三维几何。环境光、纹理与光丝由程序生成，场景材质会预先准备，缩略图由同一组三维场景实际渲染。模型、推理运行时与标题字体均随网站部署，无需第三方 API 密钥。

第三方许可与模型来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。
