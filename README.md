# 掌间交互

一座可以用双手探索的数字艺术展。支持电脑与手机，开启摄像头后，手掌就是场景的控制器。也可以直接拖动、缩放、点击游玩。

**公开体验地址：https://zhangjian-jiaohu.pages.dev/**

当前版本为 **2.3.0 公开体验完善版**：首页只创建当前作品，其余在首次切换时创建并缓存；预览图提前导出，避免进入时同时准备五个场景。增加按需下载的自有示例相册、保留完整构图的横竖照片、独立欣赏与逐张切换、手势信号平滑和捏合滞回，以及作品介绍、隐私说明与反馈入口。大屏渲染设置像素预算；手机沉浸模式也可以直接保存画面。

保留首次演绎、可选手势与本地照片、识别资源按需下载、摄像头提示、画面恢复、减少动态、保存图片和体验链接分享。

## 开始体验

首次访问会自动播放一轮约十八秒的演绎，随后交回控制。开启系统「减少动态效果」、选择本网站的减少动态模式或启用浏览器省流量偏好时，不会自动播放。点击「观看自动演绎」可主动播放。

1. 先选择底部的系统作品，再点击「直接探索」或「触屏探索」。拖动旋转，滚轮或双指缩放，滑杆控制聚散。
2. 想用手势时，再点击「开启手势」，允许摄像头权限。页面显示识别组件准备、模型下载进度和启动状态；可以随时取消。手机使用前置摄像头。
3. 可选：点击作品栏旁的「照片与示例」。可先用本站三张光影作品图体验，也能选择自己的照片。1 张也能玩，建议先用 1～9 张，最多二十四张。照片保留完整构图，可轻触或捏合放大。

加入照片后，点击「欣赏照片」进入专门的浏览界面。左右按钮或方向键可以逐张切换，按 Escape 或点击「返回作品」即可返回三维场景。画面会根据导航栏和视口重新取景，横竖照片不再统一裁成正方形；极端宽高比使用留白保留完整画面。

示例相册只在主动选择后下载，不计入首次访问所需资源。三张示例均由本站三维场景导出，无人物照片、无摄像头画面。已加入的示例不会重复添加，关闭准备窗口或清空照片可取消尚未完成的示例导入。

当手部暂时丢失时，界面会短暂等待再提示，避免状态闪烁；持续未识别会提示完整入镜、靠近镜头或直接探索。画面持续偏暗时会建议补光，亮度采样只在浏览器内进行。

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 展开、散开；花朵先绽放，再飘散 |
| 握紧拳头 | 聚合；花朵收拢成花苞 |
| 左右上下移动手掌 | 转动场景 |
| 拇指与食指捏合 | 抓住照片，或拖动场景 |
| 只伸出食指 | 在空中画出星尘 |
| 保持胜利手势约一秒 | 切换下一个造型 |
| 保持竖拇指约一秒 | 定格、继续动画 |
| 双手拉开、靠拢 | 放大、缩小场景 |

手机也支持单指拖动与双指缩放。电脑可以拖动、滚轮缩放，空格键切换展开与聚合。电脑作品右侧提供展开、定格、复位和保存图片按钮；手机点击画面右侧「⋯」即可展开这些操作。

轻触空白处或作品会唤起一圈光波；已经加入照片时，轻触照片仍优先欣赏照片。把焦点移到三维画面后，按回车键也能触发光影回应。手势模式下，完整张开手掌会触发一次回应，收拢再张开可以重新触发，持续张开不会反复闪烁。减少动态模式保留轻微的静态光晕反馈。

滑杆下方提供三个观赏阶段：星环／轨道／星系、凝聚／心动／星团、成树／流光／星雨、花苞／盛放／花雨、静游／潮汐／微光群。点击阶段会交回鼠标或触屏控制，手势相机关闭，避免手势立刻覆盖手动选择；滑杆也采用相同规则。重新开启手势即可继续隔空控制。

拖动聚散滑杆可以慢慢探索中间形态；花朵依次经历花苞、绽放、飘散。点击「沉浸观看」，会收起介绍与造型卡，把画面交给三维世界；摄像头开关仍然保留，点击「返回操作」即可恢复界面。

沉浸观看时，顶部提供「保存当前画面」，手机也可直接保存。页脚「关于作品」介绍用途、设备建议、照片与摄像头的处理方式，以及开源代码和公开反馈入口。

## 保存与分享

点击左下角「保存与分享」，或通过场景工具中的保存按钮打开预览。保存的是当前三维画面，不包含摄像头预览。支持原生分享的设备可分享图片或体验链接，其余设备可保存图片、复制链接。

图片会包含画面中的照片；欣赏单张照片时只保存当前这一张与光影背景。体验链接只记录系统作品和聚散状态，不包含照片。例如 `?world=heart&spread=80` 会打开爱心的对应展开形态，不会自动演绎覆盖它。

页面底部「减少动态」会停止背景自主漂游与呼吸，保留手动旋转、缩放和聚散；显式选择演绎时可以主动观看动态。系统减少动态偏好也会自动生效，用户手动设置优先。

三维画面中断时会停止相机，等待浏览器恢复后重建光影资源；原有照片保留在内存中。若自动恢复失败，可重新加载，但会清空本次照片。

## 本地运行

需要 Node.js 20.19 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5188/`。本机 localhost 可以开启摄像头；通过手机访问时，需要使用已发布的 HTTPS 网址。

```sh
npm test
npm run build
```

构建结果位于 `dist/`，可以部署到 Cloudflare Pages 等静态托管平台。

## Cloudflare Pages

```sh
npx wrangler@4.151.1 login --scopes account:read user:read pages:write
npx wrangler@4.151.1 pages project create zhangjian-jiaohu --production-branch main --force
npx wrangler@4.151.1 pages deploy dist --project-name zhangjian-jiaohu --branch main
```

本项目已经创建并发布，后续更新只需执行部署命令，无需重复创建项目。修改源代码后，运行测试与构建，再推送 GitHub 并执行部署。首页维持重新校验；带哈希的前端资源以及手势运行时、模型使用长缓存。模型资源更新时需要同步变更其版本查询参数与下载字节数。不要把账户令牌放入源代码。

## 隐私与兼容

- 摄像头画面、手势推理和照片处理均在浏览器内完成，不上传服务器，不使用麦克风。
- 照片仅保留在本次页面的内存中，刷新后清空。单张图片上限 25 MB。
- 切到后台或离开页面会关闭摄像头；回到页面后可手动再次开启。
- 需要支持 WebGL、WebAssembly、摄像头权限的现代浏览器。手机建议用系统浏览器打开；应用内浏览器若无法请求摄像头，可选择「在浏览器中打开」。
- 手机自动降低实例数量与像素密度，并以约三十帧的渲染目标控制负担；可在页面底部选择「流畅优先」。较低画质仍会保留完整的树冠与造型分布。
- 普通照片格式由浏览器解码。无法读取 HEIC 等格式时，可改用 JPEG 或 PNG。

## 实现

Three.js 负责三维实体、实例渲染、物理材质和辉光；动态雾光、浮尘、轨道与柔光底座均由浏览器程序生成。MediaPipe Hand Landmarker 负责两只手的关键点识别。心形使用隐式曲面生成，散开的小爱心也使用真实三维几何。首页仅准备当前作品，其他造型按需创建并缓存。缩略图为同一组三维场景提前导出的图片，更新模型时需同步更新预览图及其版本参数。模型与推理运行时均随网站部署，无需第三方 API 密钥。界面使用设备上的中文字体，避免等待额外字体下载。

手势信号使用时间相关平滑、短暂姿态确认和捏合滞回，减少位置噪声与频繁抓取释放；两只手按空间距离匹配历史。自动测试覆盖这些规则，实际识别效果仍依赖光线、入镜位置和设备。
