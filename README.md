# 掌间交互

一座可以用双手探索的数字艺术展。支持电脑与手机，开启摄像头后，手掌就是场景的控制器。也可以直接拖动、缩放、点击游玩。

**公开体验地址：https://zhangjian-jiaohu.pages.dev/**

当前版本为 **4.0.0 光影剧场**。重做首屏构图、作品导航与手机布局，加入五幕连续演出和随聚散流动的光轨；保留相册、手势、触屏和鼠标交互。

## 4.0 的变化

- 首屏采用更大的中文标题、完整的作品舞台和横向作品导航；手机作品栏可横滑，选中作品会自动进入可见区域。布局样式按舞台、弹窗与剧场拆分，替换原有叠加规则。
- 新增约八十秒的「光影剧场」：星际、心动、记忆、盛放、深海依次展开与收拢，有章节标题、分幕进度与缓慢转动的视角。
- 支持点选章节、暂停、继续、从头观看和返回探索。暂停时跳章直接显示完整造型；后台停留不会跳过演出，回到页面后由用户继续。
- 可保存当前这一幕，保存窗口会暂停演出，关闭后仍停留在原进度。演出中暂时收起本次相册，返回探索后照片及排布保留；演出截图不包含相册照片。
- 加入一个共享绘制的流光层：星际与心动的弧光、花园的流线、记忆之树的下落光迹和深海的上升微光，跟随聚散变化，并沿用设备画质预算。
- 手机竖屏、小屏与横屏分别安排标题、作品、章节和操作位置；无需摄像头即可观看剧场，开启手势仍由用户主动选择。
- 五张新版作品预览与分享封面来自网站实际渲染，五张大图合计约 300 KB；导航缩略图使用小尺寸版本，作品目录仍按需加载大图。

## 3.1 的变化

- 照片欣赏界面加入缩略图选片、手机单指左右滑动与每五秒切换的自动播放。手动切换、打开窗口、切到后台或返回作品时暂停播放。
- 放大照片时，从本次选择的原图准备最长边不超过 1536 像素的纹理；仅保留当前一张，切换或退出后释放，快速切换会取消旧任务。普通场景仍使用较小纹理，原图较小时不会强行放大。
- 手势提示说明当前操作及下一步，区分抓取照片、拖动作品、双手缩放与需要保持的手势；修正骨架叠层与摄像头预览的镜像方向。
- 识别运行出错会关闭摄像头并提供重试。调整手机提示与相册导航的避让，单张照片自动收起播放和缩略图。

## 3.0 的变化

- 五个世界分别加入星云与小行星带、心动光轨、金色雪光、花园丝光与深海光束，作品仍为实时三维渲染。爱心保留完整体积与散开的小爱心。
- 新增作品目录，使用本站真实渲染导出的预览图。五张大图合计约 450 KB，只在打开目录时加载。
- 可主动开启约七十秒的自动巡展，依次探索五件作品的聚合、展开和收拢。直接操作、选择作品或打开窗口可接管。

- 相册增加随作品、环绕画廊、星光展墙三种排布，展墙模式收起主体造型，让照片成为主角；完整横竖构图、单张欣赏和逐张切换继续保留。

## 开始体验

首次访问会自动播放一轮约十八秒的演绎，随后交回控制。开启系统「减少动态效果」、选择本网站的减少动态模式或启用浏览器省流量偏好时，不会自动播放。点击「单件演绎」可主动播放。

点击首屏「光影剧场」，或从作品目录进入，可主动观看五幕、约八十秒的演出。章节可直接点选；暂停、继续、从头观看和返回探索始终保留。按 Escape 可返回探索，空格可暂停或继续。演出结束后自动回到当前作品的探索界面。切到后台会暂停，回到页面后需主动继续。

1. 先选择作品栏中的系统作品，再点击「直接探索」或「触屏探索」。拖动旋转，滚轮或双指缩放，滑杆控制聚散。
2. 想用手势时，再点击「开启手势」，允许摄像头权限。页面显示识别组件准备、模型下载进度和启动状态；可以随时取消。手机使用前置摄像头。
3. 可选：点击顶部的「我的相册」（手机为相册图标）。可先用本站三张光影作品图体验，也能选择自己的照片。1 张也能玩，建议先用 1～9 张，最多二十四张。照片保留完整构图，可轻触或捏合放大。在相册中还可以选择三种排布，回到作品后查看。

加入照片后，点击「欣赏照片」进入专门的浏览界面。可点选底部缩略图、使用左右按钮或方向键，手机也可单指左右滑动切换。播放按钮会每五秒切换一张；手动选片、打开窗口、切到后台或退出欣赏都会暂停，自动播放会先退出摄像头控制。按 Escape 或点击「返回作品」即可返回三维场景。画面会根据导航栏和视口重新取景，横竖照片保留完整构图；极端宽高比使用留白保留完整画面。

放大后的清晰纹理只为当前照片准备，切换或退出即释放；读取失败时仍显示标准画面。原图仅保留在本次页面内存，用于清晰查看，不会上传，移除照片或刷新页面后清空。

示例相册只在主动选择后下载，不计入首次访问所需资源。三张新版示例使用 WebP，均由本站三维场景导出，无人物照片、无摄像头画面。已加入的示例不会重复添加，关闭准备窗口或清空照片可取消尚未完成的示例导入。

当手部暂时丢失时，界面会短暂等待再提示，避免状态闪烁；持续未识别会提示完整入镜、靠近镜头或直接探索。画面持续偏暗时会建议补光，亮度采样只在浏览器内进行。

手势识别运行出错时会停止摄像头、释放视频流，并显示「重试手势」入口；重新开启后可再试。

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 展开、散开；花朵先绽放，再飘散 |
| 握紧拳头 | 聚合；花朵收拢成花苞 |
| 左右上下移动手掌 | 转动场景 |
| 拇指与食指捏合 | 抓住照片，或拖动场景 |
| 只伸出食指 | 在空中画出星尘 |
| 保持胜利手势约一秒 | 切换下一个造型 |
| 保持竖拇指约一秒 | 定格、继续动画 |
| 双手拉开、靠拢 | 放大、缩小场景 |

手机也支持单指拖动与双指缩放。电脑可以拖动、滚轮缩放，空格键切换展开与聚合。电脑作品右侧提供展开、定格、复位和保存图片按钮；手机点击「随心塑形」旁的操作按钮即可展开这些操作。

轻触空白处或作品会唤起一圈光波；已经加入照片时，轻触照片仍优先欣赏照片。把焦点移到三维画面后，按回车键也能触发光影回应。手势模式下，完整张开手掌会触发一次回应，收拢再张开可以重新触发，持续张开不会反复闪烁。减少动态模式保留轻微的静态光晕反馈。

滑杆下方提供三个观赏阶段：星环／轨道／星系、凝聚／心动／星团、成树／流光／星雨、花苞／盛放／花雨、静游／潮汐／微光群。点击阶段会交回鼠标或触屏控制，手势相机关闭，避免手势立刻覆盖手动选择；滑杆也采用相同规则。重新开启手势即可继续隔空控制。

拖动聚散滑杆可以慢慢探索中间形态；花朵依次经历花苞、绽放、飘散。点击「沉浸观看」，会收起介绍与造型卡，把画面交给三维世界；摄像头开关仍然保留，点击「返回操作」即可恢复界面。

沉浸观看时，顶部提供「保存当前画面」，手机也可直接保存。光影剧场中的「留住这一幕」会暂停演出并打开图片预览，关闭窗口后可主动继续。剧场暂时收起本次加入的照片，返回探索后恢复相册与排布。页脚「关于作品」介绍用途、设备建议、照片与摄像头的处理方式，以及开源代码和公开反馈入口。

## 保存与分享

点击右上角「留住此刻」（手机为保存图标），或通过场景工具中的保存按钮打开预览。可选择无损 PNG 或更小的 WebP，保存的是当前三维画面，不包含摄像头预览。支持原生分享的设备可分享图片或体验链接，其余设备可保存图片、复制链接。

图片会包含画面中的照片；欣赏单张照片时只保存当前这一张与光影背景。体验链接只记录系统作品、聚散状态与光影风格，不包含照片。例如 `?world=heart&spread=80` 会打开爱心的对应展开形态，不会自动演绎覆盖它。

「画面设置」中的「减少动态」会停止背景自主漂游与呼吸，保留手动旋转、缩放和聚散；显式选择演绎时可以主动观看动态。系统减少动态偏好也会自动生效，用户手动设置优先。

三维画面中断时会停止相机，等待浏览器恢复后重建光影资源；原有照片保留在内存中。若自动恢复失败，可重新加载，但会清空本次照片。

## 本地运行

需要 Node.js 20.19 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5188/`。本机 localhost 可以开启摄像头；通过手机访问时，需要使用已发布的 HTTPS 网址。

```sh
npm test
npm run build
```

构建结果位于 `dist/`，可以部署到 Cloudflare Pages 等静态托管平台。

Windows 本地预览不监视 `public/artworks/` 和 `public/samples/` 的二进制文件变化，以免图片写入时的文件锁中断服务；向这些目录新增文件后需重启预览服务，再刷新页面。

## 隐私与兼容

- 摄像头画面、手势推理和照片处理均在浏览器内完成，不上传服务器，不使用麦克风。
- 照片仅保留在本次页面的内存中，刷新后清空。单张图片上限 25 MB。
- 切到后台或离开页面会关闭摄像头；回到页面后可手动再次开启。
- 需要支持 WebGL、WebAssembly、摄像头权限的现代浏览器。手机建议用系统浏览器打开；应用内浏览器若无法请求摄像头，可选择「在浏览器中打开」。
- 手机自动降低实例数量与像素密度，并以约三十帧的渲染目标控制负担；可在「画面设置」中选择「流畅优先」。较低画质仍会保留完整的树冠与造型分布。
- 普通照片格式由浏览器解码。无法读取 HEIC 等格式时，可改用 JPEG 或 PNG。

## 实现

Three.js 负责三维实体、实例渲染、物理材质和辉光；动态雾光、浮尘、轨道与柔光底座均由浏览器程序生成。MediaPipe Hand Landmarker 负责两只手的关键点识别。心形使用隐式曲面生成，散开的小爱心也使用真实三维几何。首页仅准备当前作品，其他造型按需创建并缓存。缩略图为同一组三维场景提前导出的图片，更新模型时需同步更新预览图及其版本参数。模型与推理运行时均随网站部署，无需第三方 API 密钥。界面使用设备上的中文字体，避免等待额外字体下载。

手势信号使用时间相关平滑、短暂姿态确认和捏合滞回，减少位置噪声与频繁抓取释放；两只手按空间距离匹配历史。自动测试覆盖这些规则，实际识别效果仍依赖光线、入镜位置和设备。
